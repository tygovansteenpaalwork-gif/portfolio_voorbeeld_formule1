Portfolio F1
Deze portfolio is geïnspireerd op de Formule 1 en Max Verstappen. Ik heb de website zelf gemaakt met HTML, CSS en JavaScript. Het doel was om een simpele maar leuke website te maken met een F1-thema.

Tijdens dit project heb ik geoefend met het maken van een duidelijke website-indeling, het stylen van verschillende onderdelen en het toevoegen van interactie met JavaScript. Ik heb hierbij ook gekeken naar de kleuren en uitstraling van Formule 1.
